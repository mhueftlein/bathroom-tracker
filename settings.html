Setup Guide

Getting Started

This application tracks bathroom cleaning and stores records in Google Sheets. To get it working, you need to set up Google Sheets API credentials.

Google Sheets Setup

  1. Create a Google Sheet: Go to Google Sheets and create a new spreadsheet named "Bathroom Cleaning Records"
  2. Set up the sheet headers: In the first row, add these columns:
    Timestamp | Bathroom | Initials | Tasks Completed
  3. Enable Google Sheets API:
    • Go to Google Cloud Console
    • Create a new project (or select existing one)
    • Search for "Google Sheets API" and enable it
    • Search for "Google Drive API" and enable it
  4. Create a Service Account:
    • In Google Cloud Console, go to "Service Accounts"
    • Click "Create Service Account"
    • Fill in the name (e.g., "Bathroom Cleaner")
    • Click "Create and Continue"
    • Skip the optional steps and click "Done"
  5. Create a key:
    • Find your service account in the list
    • Click on the service account email
    • Go to "Keys" tab
    • Click "Add Key" → "Create new key"
    • Select "JSON" and click "Create"
    • A JSON file will download - save this safely
  6. Share your Google Sheet:
    • Open your Google Sheet
    • Click "Share"
    • Paste the service account email (looks like: serviceaccount@project.iam.gserviceaccount.com)
    • Give it "Editor" permission
✓ Required for data storage

Deploying to Netlify

  1. Upload to GitHub: Push your project to GitHub (create a new repo if needed)
  2. Connect to Netlify:
    • Go to Netlify and sign in
    • Click "Add new site" → "Import an existing project"
    • Connect your GitHub account and select your repository
  3. Set Environment Variables:
    • In Netlify, go to your site "Settings" → "Build & deploy" → "Environment"
    • Add the following variables from your JSON key file:
      GOOGLE_SHEETS_ID=your_spreadsheet_id
      GOOGLE_SERVICE_ACCOUNT_EMAIL=your_service_account_email
      GOOGLE_PRIVATE_KEY=your_private_key
      GOOGLE_PROJECT_ID=your_project_id
    • Find spreadsheet_id from your Google Sheet URL:
      https://docs.google.com/spreadsheets/d/[spreadsheet_id]/edit
  4. Configure Build Settings: Your project should have a netlify.toml file configured (already included)
  5. Deploy: Netlify will automatically deploy when you push to GitHub
✓ Makes site live online

QR Code Setup

Once deployed, your site will be at https://your-site-name.netlify.app

  1. Use a QR code generator (e.g., QR Code Generator)
  2. Generate QR codes for each bathroom URL:
    https://your-site.netlify.app/form.html?bathroom=mens
    https://your-site.netlify.app/form.html?bathroom=womens
    https://your-site.netlify.app/form.html?bathroom=accessible
  3. Print and laminate the QR codes
  4. Post them in each bathroom for employees to scan

Testing

  • Test locally: netlify dev
  • Fill out a cleaning form to verify it submits
  • Check your Google Sheet to confirm data appears
  • View the dashboard to see records
